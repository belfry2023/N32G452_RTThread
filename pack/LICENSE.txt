N32G452 RT-Thread local integration pack
======================================

This is a user-maintained integration package, not an official Nations,
RT-Thread, LVGL or Arm release. Package version: 0.1.2.

Modified third-party material:
- RT hwtimer.c: add the missing break after HWTIMER_CTRL_INFO_GET.
- RT context ports: align the MSP before the HardFault C diagnostic call;
  add GNU EABI stack alignment attributes for armlink interoperability.
- Nations startup: fixed MSP/heap reservations for Keil scatter loading;
  the AC6 syntax variant retains the N32G45x interrupt vector list.
The upstream SDK checkout is not edited by the pack builder.
